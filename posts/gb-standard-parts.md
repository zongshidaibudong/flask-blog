## 需求

画装配图时经常要查：GB/T 6170 螺母的对边宽度、GB/T 97.1 垫圈的内外径……
翻手册 → 找表格 → 对尺寸，一次要花好几分钟，还容易抄错。

## 实现思路

把常用标准件的尺寸表存成字典，写一个查询函数：

```python
GB6170_NUT = {
    # 规格: (对边宽度 s, 厚度 m, 螺纹大径 d)
    "M6":  (10, 5.2, 6),
    "M8":  (13, 6.8, 8),
    "M10": (16, 8.4, 10),
    "M12": (18, 10.8, 12),
}

def query_nut(spec: str) -> str:
    """查询 GB/T 6170 1型六角螺母尺寸"""
    if spec not in GB6170_NUT:
        return f"未收录规格 {spec}，请查阅手册"
    s, m, d = GB6170_NUT[spec]
    return f"GB/T 6170 {spec}: 对边 {s} mm，厚度 {m} mm"

print(query_nut("M10"))
# GB/T 6170 M10: 对边 16 mm，厚度 8.4 mm
```

## 进阶方向

1. 把尺寸表放进 `json` 文件，方便持续补充
2. 加上 GB/T 97.1 垫圈、GB/T 68 螺钉等常用件
3. 对接 NX API，查询后直接在模型里创建对应零件

## 小结

标准化的意义就是让机器可以代替人查表。
手册数据的电子化 + 脚本查询，是机械工程师最容易上手的第一批编程项目。
